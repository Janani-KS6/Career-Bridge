# CareerBridge — Multi-page Job Portal Frontend

## Technologies
- HTML5
- CSS3
- Tailwind CSS (CDN)
- No JavaScript

## Pages
- `index.html` — Home
- `jobs.html` — Job listings and filter form
- `about.html` — About and how it works
- `contact.html` — Contact form
- `login.html` — Login form
- `register.html` — Registration form
- `apply.html` — Job application form
- `profile.html` — Static candidate profile preview

## How to run
1. Extract the ZIP.
2. Open the `CareerBridge` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.
4. Internet is required for Tailwind CDN, Google Fonts and remote Unsplash images.

## Important limitations
This is a static frontend learning project. Forms use native HTML validation, but no account is created, no password is checked, no form data is stored, and no resume/message is uploaded. Job listings are illustrative examples, not live verified vacancies. Dynamic search/filtering requires JavaScript or backend functionality, intentionally not included per the requested stack.
